Aurelia Sync

A Jellyfin plugin that gives the Aurelia music client a resumable, ordered library sync protocol.

Add this repository to Jellyfin

Dashboard → Plugins → Repositories → Add, and paste this URL:

https://gunnarbeutner.github.io/AureliaSync/manifest.json
  1. Open the Catalog and install Aurelia Sync.
  2. Restart Jellyfin. Plugin API routes are registered at startup, so they do not exist until the server restarts.
  3. Aurelia detects the plugin automatically on its next connection.

Requirements

Jellyfin10.11.x
Target ABI10.11.0.0
Runtimenet9.0

What it does to your server

Nothing destructive. The plugin only ever reads from Jellyfin — it never writes to the Jellyfin database and never calls a mutating Jellyfin API. All of its own state lives in a separate SQLite database under the Jellyfin data directory, so uninstalling leaves the server exactly as it was found.
